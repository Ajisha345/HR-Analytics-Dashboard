# HR-Analytics-Dashboard

## Overview
This project is a Power BI dashboard to analyze employee data like attrition, salary, and performance.

## Tools Used
Power BI, Excel

## Key Insights
- Some departments have higher attrition  
- Salary does not always increase satisfaction  
- Most employees fall under average performance  
- Employee distribution varies across departments  

## Features
- Attrition analysis  
- Salary vs satisfaction  
- Department-wise performance  
- Employee distribution
